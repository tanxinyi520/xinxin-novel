# 笔趣阁桌面版

一款基于Electron开发的现代化小说阅读桌面应用，支持Windows平台。

## 功能特性

- 📚 海量小说资源，涵盖各种分类
- 🎨 现代化UI设计，舒适阅读体验
- ⚡ 响应式界面，适配不同屏幕尺寸
- 🔍 强大的搜索功能，快速找到心仪小说
- 📱 书架管理，方便收藏喜爱的作品
- 📖 阅读历史记录，随时随地继续阅读
- 🌙 支持暗黑模式，保护眼睛

## 安装指南

### 前提条件

在安装应用之前，确保您的系统已经安装了以下软件：
- [Node.js](https://nodejs.org/) (v14.0.0或更高版本)
- [npm](https://www.npmjs.com/) (通常随Node.js一起安装)

### 开发环境设置

1. 克隆或下载本项目到本地

2. 进入项目目录
   ```bash
   cd electron_app
   ```

3. 安装依赖
   ```bash
   npm install
   ```

4. 启动开发服务器
   ```bash
   npm start
   ```

## 构建应用

要构建可分发的Windows安装包，请执行以下命令：

```bash
npm run package
```

构建完成后，可执行文件将位于`dist`目录中。

## 主要页面说明

### 首页 (index.html)
- 显示热门小说推荐
- 提供分类浏览功能
- 包含搜索入口和导航菜单

### 阅读页面 (read.html)
- 沉浸式阅读体验
- 支持字体大小、行间距调整
- 提供多种阅读主题（浅色、深色、护眼模式等）
- 支持章节切换和书签功能

### 小说详情页面 (novel_detail.html)
- 展示小说的详细信息
- 提供章节列表浏览
- 支持加入书架和立即阅读功能

### 搜索页面 (search.html)
- 支持按关键词搜索小说
- 提供搜索历史和热门搜索推荐
- 支持按分类、更新时间等筛选结果

### 书架页面 (bookshelf.html)
- 管理已收藏的小说
- 显示阅读进度
- 提供最近阅读记录
- 支持按分类筛选和排序功能

### 用户中心页面 (user.html)
- 个人信息展示
- 阅读统计数据
- 应用设置入口
- 提供登录/注册功能

## 开发说明

### 主进程和渲染进程

Electron应用包含两个主要进程：
- **主进程** (`main.js`): 负责创建和管理浏览器窗口，以及处理系统级别的事件
- **渲染进程** (`index.html`, `read.html`等): 负责应用的UI渲染和用户交互

### 进程间通信

使用`ipcMain`和`ipcRenderer`进行主进程和渲染进程之间的通信。`preload.js`文件提供了安全的API暴露机制。

### 添加新功能

1. 根据功能需求创建新的HTML页面（如果需要）
2. 在HTML文件中添加UI元素和样式
3. 在HTML文件底部的`<script>`标签中添加交互逻辑
4. 如果需要访问系统功能，在`preload.js`中暴露相应的API
5. 在`main.js`中实现系统级别的功能
6. 更新README.md以记录新功能
