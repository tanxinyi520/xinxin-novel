Node.js 手动安装指南

1. 安装包已下载到以下位置：
   C:\Users\谭心怡\AppData\Local\Temp\nodejs_temp\nodejs_installer.msi

2. 请手动运行此安装包，并确保在安装过程中执行以下操作：
   - 勾选 "Add to PATH" 选项（这是最重要的一步）
   - 使用默认安装路径即可
   - 安装完成后，重新打开命令提示符

3. 验证安装是否成功：
   - 打开新的命令提示符
   - 运行命令：node --version （应该显示版本号）
   - 运行命令：npm --version （应该显示版本号）

4. 安装项目依赖并启动应用：
   - 在命令提示符中导航到项目目录：cd h:\编程项目\小说软件\electron_app
   - 运行命令：npm install （安装项目依赖）
   - 运行命令：npm start （启动应用）

如果遇到任何问题，请参考项目目录下的"手动安装运行指南.md"文件。
